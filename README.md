# Customer Churn and Revenue Analytics
Feb-May 2021
Analyzed 7,000+ telecom customer records with SQL cohort retention and RFM segmentation, identifying $1.5M in at-risk recurring revenue across 4 customer segments.
Modeled the data in Power BI with a star schema, DAX measures, and row-level security by region, then rebuilt the executive dashboard in Tableau.
Delivered a one-page executive memo recommending 3 targeted retention actions projected to lift 12-month retention by 8%.
Tech: SQL, Power BI, DAX, Tableau, Excel

# Customer Churn and Revenue Analytics — Starter Code & Data

Starter project for the GitHub repository
`customer-churn-revenue-analytics`.

**Important — synthetic sample only:** No original code was found, so
all data here is newly generated SYNTHETIC sample data for
demonstration. The sample run does **not** reproduce the original
project's figures, including the original $1.5M at-risk revenue,
4-segment, or +8% retention figures from the LinkedIn description.
At-risk revenue computed here is sample-only:
`sum(monthly_charges * 12)` for churned customers in the sample file.

Power BI and Tableau files (`.pbix` / `.twbx`) are **NOT included**.
`dax_measures.txt` and `tableau_notes.md` show how to rebuild those
views from `data/sample_customers.csv`.

## What each file does

- `data/sample_customers.csv` — 1,000 synthetic rows generated with
  seed 42. Columns: `customer_id`, `region`, `segment`,
  `tenure_months`, `monthly_charges`, `total_charges`,
  `contract_type`, `payment_method`, `churn` (0/1). Regions: North,
  South, East, West. Segments are derived from tenure/charges logic
  in the generator (Early Tenure; Mid Tenure - Standard; Mid Tenure -
  Premium; Long Tenure) — documented in the generator, not claimed to
  be the original project's segments.
- `src/generate_sample_data.py` — Deterministically regenerates the
  CSV (seed 42 by default). Run it to recreate the sample data.
- `src/analysis.py` — pandas + matplotlib analysis: churn rate
  overall and by segment/region/contract, sample-only at-risk revenue,
  RFM summary (with documented tenure/total_charges proxies), and
  charts in `outputs/charts/`.
- `sql/cohort_retention.sql` — Cohort retention by tenure bucket
  (proxy for signup cohort, since the sample has no signup date).
- `sql/rfm_segmentation.sql` — RFM-style segmentation with documented
  proxies (recency/frequency = tenure, monetary = total_charges).
- `dashboard/app.py` — Streamlit dashboard: churn KPIs, churn by
  segment/region/contract, and a sample-data table. Uses Streamlit
  charts/tables only, no matplotlib required in the app.
- `dax_measures.txt` — Example DAX measures for a Power BI
  star-schema model: Total Customers, Churn Rate, At-Risk Revenue,
  Avg Monthly Charges.
- `tableau_notes.md` — How to rebuild the executive dashboard in
  Tableau: churn by segment, churn by region, revenue at risk.
- `requirements.txt` — pandas, matplotlib, streamlit.
- `outputs/charts/` — Generated by `src/analysis.py`:
  `churn_by_segment.png`, `churn_by_contract.png`,
  `monthly_charges_distribution.png`,
  `at_risk_revenue_by_segment.png`.

## How to run the analysis

```bash
pip install -r requirements.txt
python3 src/generate_sample_data.py
python3 src/analysis.py
# charts appear in outputs/charts/
```

## How to run the Streamlit app

```bash
pip install -r requirements.txt
streamlit run dashboard/app.py
```

The app reads `data/sample_customers.csv` from the project root.
Run `python3 src/generate_sample_data.py` first if the CSV is missing.
